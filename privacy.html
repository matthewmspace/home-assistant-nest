Privacy Policy

Home Assistant Nest Integration

Last updated: September 13, 2026

Overview

The Home Assistant Nest Integration is a personal application used to connect a Home Assistant installation with compatible Google Nest devices through Google's Smart Device Management API.

Google Account Data

When you authorize this application, Google provides the application with access to the Google Account and Nest device data necessary for the integration to operate.

This information is used solely to provide the requested Home Assistant functionality, including retrieving information about authorized Nest devices and sending authorized commands to those devices.

Storage and Sharing

The application does not sell Google user data and does not use Google user data for advertising.

OAuth credentials and device information may be stored by the Home Assistant installation using the integration. This information is not intentionally shared with third parties except as necessary to communicate with Google's services and the authorized Nest devices.

Data Retention

Data remains available only as long as it is needed for the Home Assistant integration to operate. Removing the integration or its stored credentials from Home Assistant removes the application's stored access credentials from that installation.

Contact

For questions regarding this application or this privacy policy, please use the developer contact information associated with the Google Cloud project.
